Сортировка подсчетом
Это сортировка за линейное время, работающая без сравнения элементов между собой
Условие: диапазон возможных значений чисел должен быть известен заранее

Основная идея:
1. Считаем, сколько раз каждое число ввстречается в исходном массиве
2. Зная это, вычисляем, с какой позиции должны начинаться элеменвты каждого числа
    в отсортированном массиве
3. Проходим по исходному массиву и ставим каждый элемент сразу на его правильное место

Псевдо-код:
arr - исходный массив (к примеру в диапазоне 250-400)
в цикле можно найти минимальны и максимальный элементы
arr_count - массив подсчета (его длина - 151), где все элементы пока равны 0
для каждого i индекса в arr:
    по индексу arr[i]-250 в arr_count увеличиваем счетчик на 1
int j = 0 - текущий индекс в arr
для каждого i индекса в arr_count:
    для каждого _ в arr_count[i]:
        arr[j] = i+250
        j++

Доказательство линейности:
O(n+k), где n - кол-во элементов
            k - маскимально значение ключа
1. подсчет частот - это проход по всем n элементам (то есть O(n))
2. далее проходим по массиву из k элементов (то есть O(k))
3. расстановка элементов в выходной массив (O(n))
Суммарно O(n)+O(k)+O(n) = O(n+k)
