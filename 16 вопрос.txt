Кнут-Моррис-Пратт

Для строки s длиной n значение sp[i] равно длине наибольшего собственного префикса подстроки s[0 ... i], который одновременно является ее суффиксом
sp - префиск-функция (некий аналог з-фукции)

Построение по Z-функции:
Если z[j] > 0, то подстрока s[j..j+z[j]-1] совпадает с префиксом.
Значит, для каждой позиции p = j + t - 1, где 1 ≤ t ≤ z[j], на подстроке s[0..p] есть граница длины t = p - j + 1.
Длина границы тем больше, чем левее j.
Поэтому для позиции p нужен минимальный j ≥ 1, покрывающий p, то есть j ≤ p < j + z[j].

Идём по j слева направо и для каждого j просматриваем позиции справа налево, от j + z[j] - 1 до j.
Позицию, у которой π уже задано, не перезаписываем.
На первой же такой позиции цикл прерываем.
