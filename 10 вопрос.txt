Trie - это такое дерево, которое составляется посимвольно из слов
После каждого символа, означающего конец слова, ставится символ $

Из корня у нас выходят первые символы
Сложность = O(L), где L - длина слова

Пример для car/cat/dog:
        (root)
        /    \
       c      d
       |      |
       a      o
      / \     |
     r   t    g
    (*) (*)  (*)

Вставка простая, просто всталяем по символам
Поиск тоже элементарный

Алгоритм удаления:
1. Слова нет в trie = ничего не делаем
2. Слово является префиксом другого слова. В таком случае просто снимаем флаг об окончании
3. Слово не является префиксом. В таком случае снимаем флаг и удаляем снизу вверх пока у узла нет детей и он не конец другого слова

compact trie "склеивает" цепочки ущлов с одним ребенком в одно ребро
Пример:
              (root)
                |
                r
              /   \
           om      ub
          /  \    /  \
        an   ulus e   icon / icundus
       / \          / \
      e   us      ns   r
