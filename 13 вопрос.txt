B-деревья. Основные операции. Оценка алгоритмической сложности выполнения операций.

В-дерево - сильноветвящееся дерево
Структура:
1. у корня есть дети (k1, k2, ..., kn)
2. у детей есть дети (с0, c1, ..., cn), то есть их n+1
3. гаранитруется, что c0 < k1 < c1 < k2 < ... < kn < cn
Таким образом, свойства:
1. Все листья гарантированно хранятся на 1 уровне
2. Все его вершины представляют набор ключей, ключи расположены в порядке неубывания
3. Если в узле n ключей, то объект n+1 ребенок
4. Ну и как потомки устроены описано выше
t - характеристическое число дерева, тогда t-1 <= n <= 2t-1 и 1 <= n (корень) <= 2t-1, где n - кол-во ключей

Сериализация - это пердставление дерева в блоб (структурированое хранение данных), короче запихиваем структуру в память
Десериализация - это представление дерева из блоба, короче достаем из памяти структуру
И понятно, что на выходе у нас должна получиться структура без изменений

Алгоритм поиска:
1. Ищем бинарно значение в ключах
2. Нашли его в самих ключах - ура, иначе мы нашли диапазон
3. Спускаемся ниже в узел, там ищем также

Сложность дерева представляет собой O(log2(t) * logt(n)), если дерево загружено в память.
Сложность будет представлять собой O(logt(n)) при обращении к жесткому диску

Алгоритм вставки:
1. Мы ищем вставляемый элемент в дереве (ну чтоб знать куда вставлять)
2. Вставляем, если не превышаем размер.
3. Если превышаем, то выносим центральный элемент к родителю

Алгоритм удаления. Два вида: когда n > t-1 и n = t-1
1. В первом случае просто удаляем и все
2. Во втором берем из соседнего листа
3. Если во втором случае недостаточно элементов у братьев, то объединяем их + опускаем родительский элемент
