# Теорема об оценке времени сортировок, использующих сравнение элементов (и ее доказательство)
## Сама теорема
Теорема: любой детерминированный алгоритм сортировки, использующий только сравнение элементов, в худшем случае выполняет O(n*log(n)) сравнений. А точнее для сортировки нужно не менее log2(n!) сравнений.
Понятно, что под "сортировкой сравнением" понимается алгоритм, который узнает об элементах входа информацию только через операции сравнения элементов a_i и a_j.
То есть моделью этих сортировок является дерево решений (бинарное дерево):
1. каждая вершина(узел) помечена сравнением a_i и a_j, а два ее ребенка - два возможных исхода
2. каждый путь от корня к листу задает последовательность сравнений
3. в листе алгоритм выдает ответ (перестановку), который упорядочивает вход
Даже при том, что у нас есть только 1 лист, в котором содержится верное решение алгоритма. При смене значений дерево останется таким же, просто приведет нас в другой лист.

## Доказательство
### Шаг 1. Листьев не меньше n!
Рассмотрим вход из n элементов. Как известно, для n элементов у нас n! перестановок. При это разные перестановки не могут привести к одному результату, если они все же приходят, то алгоритм где-то ошибается. Но при этом сортировка может закончиться раньше, чем мы пройдем все листья. Таким образом, у нас получается, что число листьев больше или равно n!

### Шаг 2. Бинарное дерево высоты h имеет не более 2^h листьев
Доказывается индукцией по h. Пусть утверждение верно для высоты h-1. Дерево высоты h состоит из корня двух поддеревьев высотой не (h-1), в каждом из которых не более 2^(h-1) листьев. Всего листьев не более 2*2^(h-1)=2^h. Аналогично индуцируем и для всех меньших значений

## Шаг 3. Объединяем 2 и 3
Из предыдущих шагов получаем 2^h >= L >= n!, откуда h >= log2(n!)

## Шаг 4. Оцениваем log2(n!)
В произведении n! последние n/2 множителей не меньше n/2, поэтому n! >= (n/2)^(n/2). Далее log2(n!) >= (n/2)*log2(n/2) = (n/2)*(log2(n)-1) = O(n*log(n))
Итак, h >= log2(n!) = O(n*log(n))
